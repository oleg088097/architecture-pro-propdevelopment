# Требования для интеграций - **E2EE шифрование биометрических данных.** Данные собираются в приложении собственника, шифруются и передаются в зашифрованном виде в систему PropDevelopment. Далее они так же в зашифрованном виде передаются в систему партнёра Умный Дом. Используется асимметричное шифрование, приватный ключ для расшифрования находится только у партнёра, как и собранные биометрические данные. Допустимо временное хранение зашифрованных данных в системе для обеспечения передачи данных в случае прерывания соединения с партнёрской системой. - **mTLS.** Сетевые взаимодействия с партнёром должны быть защищены по протоколу mTLS и для HTTPS, и для WSS соединений. - **API Key партнёра**. Для аутентификации запросов от системы партнёра Умный Дом используется ключ API, который предоставляется партнёру.  - **API Key клиента**. Для аутентификации запросов от клиентов в системе партнёра используется ключ API с ограниченным сроком жизни, генерируемый партнёром для каждого клиента отдельно. Успешная аутентификация клиента позвляет авторизовать ему доступ к конкретным устройствам системы Умный Дом. Ключи API клиентов хранятся на устройствах клиентов и не сохряняются в системе PropDevelopment, так же как правила авторизации запросов.
